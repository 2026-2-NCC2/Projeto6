## Descrição

<p align="center">
<img src="https://placehold.co/1000x650" alt="NOME DO JOGO" border="0">
</p>


"A TrocaTicket nasceu com o objetivo de facilitar a troca e a revenda de ingressos para festas universitárias, e com a evolução do negócio, passou a atender também outros tipos de eventos [...]"
<br><br>
O projeto TICKETBOOM propõe uma solução para a TrocaTicket com três módulos integrados: Administrador, Organizador e Fornecedor visando o planejamento de eventos, a obtenção e comparação de propostas, a consolidação dos custos e o cálculo do ticket médio estimado com base no público, nos custos e na margem de lucro definida.

<b>HTML:</b>

## 💻 Configuração para Desenvolvimento

Para abrir este projeto você necessita das seguintes ferramentas:


(Qualquer editor de código pode ser usado, como exemplo usaremos o Visual Studio Code)
- <a href="https://code.visualstudio.com/">VSCODE</a>

- <a href="https://nodejs.org/pt-br">Node JS</a>

```sh

```
